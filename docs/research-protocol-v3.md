# v3：真实现金流会计与受约束 RL 迭代

制定日期：2026-10-23；在读取新研究测试结果前固定本协议。用户目标为收益与回撤平衡。

旧腾讯 hfq 是加法复权价格，不能以其价格比代表可交易总收益。v1/v2 的业绩解释撤回，保留原文件作为复核记录。新研究采用腾讯未复权 OHLC，与东方财富未复权行情逐日交叉核对；按真实除息日确认分红应收，支付日转为可用现金，按基金公告精确份额折算比例调整持股。分红税前，现金零利息，分数份额。

固定资产为 510050、510300、510500，覆盖大中小盘宽基。排除创业板不是根据收益，而是减少行业暴露混杂、使用三只长期存续的宽基。起始日期 2015-04-15 源于510500此前两个折算停牌日；不填充、不删除中间交易日。样本截至2026-10-22。存续资产选择偏差、数据商追溯修订、观察过2022年之后市场结果的研究者偏差仍在，因此全部结果为回顾性探索，不能称为全新确认性样本外试验。

四折扩展训练，分别测试2019–2020、2021–2022、2023–2024、2025–2026-10-22；每折测试前一年用于验证，更早历史用于训练。每折从现金重新开始；初始测试日仅是决策/初始估值，不计收益。不把四折拼成连续账户，也不跨折 bootstrap。

固定四种候选：legacy_ppo（旧观测/动作/日调仓结构，修正现金流会计）；robust_ppo、robust_sac、robust_td3（三种RL，因果1/5/20/60/120日动量、20/60日波动、60日均线，持仓及调仓相位）。改进结构每5个交易日调仓，股票目标暴露80%–100%，单资产最多50%，相对于等权做有限幅度偏移。训练在训练区间内随机抽取126日片段，完整验证与测试不随机。增加股票暴露约束本身可能解释改善，必须与80%、90%、100%股票周等权、100%买入持有、90%逆波动组合同时比较。

每折每候选请求20,000步，种子7/17/29，各候选使用相同种子列表、不选最佳seed。旧PPO学习率3e-4，改进算法1e-4；风险罚系数2，旧结构风险协方差窗口20日、改进结构120日。这是整体结构迭代，不能将差异归因于某一个改动。无测试驱动的超参数扩展、无测试驱动早停。使用真实FinRL工厂创建SB3模型。记录实际训练步数、时间、数据/源代码/模型SHA256。随机片段增加采样多样性，不增加独立历史市场样本。

每候选各seed验证分数为累计净收益减0.5倍最大回撤，取三个seed的平均分；选一个共同候选供全部seed后续测试。全部折的选择冻结写入文件后，才执行任何最终测试。并列按固定候选顺序。另报告三种改进RL权重的简单平均组合，不按测试挑权重。比较固定20k最终模型，不挑测试checkpoint。

每侧费用5bps含佣金/滑点的简化总成本；冻结模型重新以10/20bps评估。应收分红不能买入资产；交易目标以可投资净值为分母，应收单列。费用以风险资产买卖两侧总额计。周调仓持有日不产生订单费用。测试净值来自原始价格、现金、份额和应收账本，不扣除风险奖励惩罚。

每折报告累计净收益、252日年化收益、最大回撤、零无风险利率Sharpe、换手、现金/股票暴露、种子差异。主要比较为验证所选策略对90%周等权；100%周等权为更严格辅助比较。对同日种子平均日收益与基准进行10日配对移动区块bootstrap（2000次），只在折内抽样。区间估计量是年化算术日超额收益，并非CAGR；所有候选完整披露，区间未作多重比较校正，不能修复研究者偏差。

优秀效果的研究判据：相对上述基准，在多个行情阶段提高净收益/风险调整表现且不明显增加回撤，成本压力后仍有优势，而非依靠少数种子或单段行情。若不满足，明确报告失败，不宣称目标已实现、不无限试参数直至出现赢家。保留改进或失败的实验数据供下一轮研究。

本轮仍为离线、分数份额、开盘成交假设。未实现逐笔盘口、真实停牌/涨跌停成交队列或券商下单。不得描述为实盘业绩。
