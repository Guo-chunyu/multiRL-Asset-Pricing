## Hypothesis and controlled design

Investigate whether suppressing policy/entropy terms from ignored non-rebalance-day requests changes learning. Use official `sb3_contrib.MaskablePPO==2.7.1` directly for BOTH arms, never claim this is FinRL's training entry. `alltrue` permits all four actions daily; `phase` permits all four when CURRENT pre-step rebalance phase is zero, otherwise only index 0. That index is an ignored dummy request, NOT cash liquidation or a queued action. No future mask, macrostep, skipped reward, new observation or changed accounting. Critic still trains on daily transitions. With effective entropy coefficient zero, no entropy-loss contribution exists in either arm; singleton masking removes action-dependent actor terms on ignored days. This is a mechanism hypothesis, not an established cause.

Two exact v6 objectives: `lognet` = 100 × daily log net return; `drawdown` = 100 × (daily log net return − 0.5 × increment of running maximum drawdown). Registry/tie order: lognet_alltrue, lognet_phase, drawdown_alltrue, drawdown_phase. Four candidates × seeds 7/17/29 × four original folds = **48 fits**, each exactly **20,000 DAILY market transitions**, totaling **960,000**. Final checkpoints only. Random 126-transition episodes, no budget search or early stopping. Actual sampled episode (start,end) sequences are recorded and checked against the same independent Gym/NumPy seeded schedule per seed/fold for every candidate. Construction's unseeded reset is discarded from this trace.

Exact effective v6 PPO configuration: MlpPolicy, CPU, hidden [64,64], learning_rate .0001, n_steps 100, batch_size 50, n_epochs 10, gamma .99, gae_lambda .95, clip_range .2, clip_range_vf None, normalize_advantage True, **ent_coef 0.0**, vf_coef .5, max_grad_norm .5, target_kl None. Important verified provenance: nominal FinRL config says ent_coef .01, but its get_model does NOT merge defaults when the v6 adapter supplies model_kwargs; actual v6 instantiated model has .0. Tests compare instantiated original v6 and both v7 arms. All control settings match; only masks differ within each objective. Evaluation predict explicitly receives the identical current mask rule.

Tests and independent pre-training review must pass BEFORE any fit. Signed baseline preview is validation-only, no test metrics. Six fixed comparators once per fold/cost: cash, equal50, vol10, trend10, equal_target_mix (mean current targets traded in ONE actual account, not mean shadow returns), trailing20 (causal shadow net-log argmax). All costs/actions retained. No family changes based on preview.

Per fold select among ALL FOUR learned candidates by mean over all three seeds of validation total return − .5 maximum drawdown. Separately select deployment across those four means plus all six scalar rule scores. Rules count once, not replicated seeds. Fixed ties follow registry then rule order; additionally freeze best individual fixed expert. All 48 checkpoints, signed training records with actual daily steps and episode schedules, validation ledgers/metrics, rule validations and exact plan/source/data hashes must be reconciled and frozen across ALL folds BEFORE any v7 test metric.
