# 数据纠错与真实现金流会计

2026-10-23 独立复核发现：旧腾讯 hfq 的 OHLC 近似为 `a × raw + b`，而非同日各价格共用的纯乘法比例。加法偏移改变收益比。以510300在2024-09-30为例，raw开/收4.007/4.233，hfq开/收1.735/1.818；前者日内收益约5.640%，后者约4.784%。当天不同价格比已不一致，无需判断是否除息日即可证明问题。

本次重新直接请求腾讯raw与hfq接口，返回分别只有day与hfqday，和本地数据一致。原4,628行日期、证券代码与成交量匹配，数据哈希匹配，排除了静默切换与错位。510050、510300旧样本的平均日内收益绝对偏差分别约13.33、10.15个基点。因此不能把旧表称为投资者能够获得的复权总收益；原始记录仍可复现，但该解释已撤回。

v3 使用三只宽基 ETF：510050、510300、510500。腾讯未复权行情和东方财富未复权行情逐日交叉核对，2015-04-15至2026-10-22共2,800日，最大OHLC差0.001元。日期×证券矩阵完整，不填补、不删除中间日。510500在2015-04-13、14因份额折算停牌，完整区间从恢复交易日开始。源数据与供应商缓存保留本地，下载脚本为 `scripts/prepare_market_data_v3.py`。

现金分红取东方财富基金分红历史表，标准化为每份现金额、除息日、支付日。25次事件的登记日均为除息前一个交易日。已抽查交易所2026年510300和510500基金公告，未声称所有事件均逐条官方核验。

- 除息日前收盘持股者取得应收分红；除息日开盘新买入者不取得该次分红。
- 应收在除息日计入净值，但支付日之前不能用于下单；支付日由应收转现金，不再产生第二次收益。
- 510500于2022-08-26日终实施份额折算，下一交易日2022-08-29开盘前按1.14539调整持股数。采用分数份额，没有模拟真实整数账户的小数向上取整。
- 成交、费用和现金均以原始价格计算；总净值=可用现金+持股市值+应收分红。
- 观察特征用因果总收益指数消除除息/拆分跳变。该指数仅用于信号与风险估计，不直接替代现金账户收益。

该修复提高会计正确性，不保证RL获得超额收益。仍有固定存续ETF选择偏差、数据商追溯修订、税前分红、零现金利息、分数份额、开盘成交假设，以及历史公告时间库不完整等限制。模型现金观察包含应收，却未显式看到剩余支付期限，因此并非完全可观测的账户状态。
