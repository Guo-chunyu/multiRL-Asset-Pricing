# v4 信息与风险配置：实现、实测与保留意见

研究日期：2026-10-25。**本轮实现了更明确的风险配置能力，但没有获得跨时期稳定的组合优化优势。新增特征也没有证明稳定的收益预测增量。** 不将最近一个表现较好的阶段替代整个历史结果。

## 做了哪些改进

1. 状态从 29 维扩展到 45 维，加入 ETF 成交量变化、下行波动、相对动量、相关性、三 ETF 趋势参与比例，以及账户回撤、可用现金和应收分红。
2. 增加分层风险配置：RL 先选择 5%–20% 年化波动预算和股票间比例，再根据因果协方差决定总股票仓位，替代原来固定 80%–100% 股票暴露的动作约束。无杠杆，目标风险不是实际风险保证。
3. PPO 做“信息开关×风险配置开关”的 2×2 消融，联合方案另用 SAC、TD3；加入同风险公式的等权/逆波动规则、50%/90%/100% 等权与买入持有。
4. 六个 RL 候选按验证表现选择，同时提供允许规则胜出的独立选择；本次四折恰好两种选择相同，均选中了 RL。没有按测试结果重选。

仅成交量是原 v3 未利用的独立行情字段；其余新增市场量主要是价格的结构化变换。研究仍限于 510050、510300、510500 三只相关性较高的长期存续宽基 ETF，没有新增新闻、财报或全市场资金流。

原始行情、分红/拆分账本、样本区间沿用纠正后的 v3。总计 **72 个模型、1,440,000 个实际训练步、3 个种子、4 个独立历史测试阶段、单边 5/10/20 bps 成本**。每个模型固定 20,000 步，不代表已经收敛。完整设置见[固定协议](research-protocol-v4.md)，代码解释见[实现说明](implementation-v4.md)。

## 验证选择的实际历史结果

以下为 5 bps 单边费用后的累计收益/最大回撤，RL 数字为三个种子的各自指标均值。每折从净值 1 独立开始，不能串起来当连续实盘。

| 测试时期 | 验证选中策略 | 新选择：收益 / 回撤 | 原 v3 结构 PPO：收益 / 回撤 | 无 RL 的10%目标波动规则：收益 / 回撤 |
|---|---|---:|---:|---:|
| 2019-01-03—2020-12-31 | joint_sac | 35.22% / 11.71% | 66.73% / 14.58% | 35.64% / 12.01% |
| 2021-01-05—2022-12-30 | signal_ppo | −18.44% / 30.91% | −16.73% / 28.37% | −15.50% / 23.08% |
| 2023-01-04—2024-12-31 | joint_ppo | −2.43% / 16.39% | 4.41% / 20.88% | −4.23% / 20.91% |
| 2025-01-03—2026-10-22 | risk_ppo | 10.56% / 9.17% | 12.45% / 15.19% | 12.66% / 9.58% |

“原 v3 结构 PPO”是本轮按相同种子、学习率、步数重新训练的 `base_ppo`，对应 v3 的 RobustPortfolioEnv，不是旧 hfq 实验，也不是 v3 每折混合候选池选出的策略。

按预先固定的“累计收益−0.5×最大回撤”衡量，新验证选择只在最近一折优于 `base_ppo`。相对于 10% 目标波动等权规则，只在第三折分数更高。模型在单年验证期获胜，没有稳定迁移到随后测试期。

低仓位基准不能省略：50% 股票等权四期收益依次为 **31.70%、−9.00%、2.90%、7.63%**，回撤依次 **7.63%、16.22%、11.97%、9.14%**。新选择在第二、第三折同时不及该基准的收益与回撤，因此不能把整套选择系统称为成功升级。

## 风险配置的增量与代价

在最近一折，单独增加风险层的 `risk_ppo` 相比 `base_ppo`：

- 最大回撤从 **15.19% 降至 9.17%**，年化波动从 **15.04% 降至 10.04%**。
- Sharpe 从 **0.527 升至 0.638**，累计收益从 **12.45% 降至 10.56%**。
- 平均股票暴露从约 **88.77% 降至 59.69%**；部分风险下降来自仓位下降。
- 平衡分数改善 **1.12 个百分点**，但同公式无 RL 规则的分数仍更高。

联合方案在这一折也呈现较好的风险收益关系：`joint_ppo` 为 12.46% 收益、9.68% 回撤；`joint_sac` 为 12.68% 收益、9.69% 回撤。然而等权波动规则已达到 12.66% 收益、9.58% 回撤，几乎解释了联合 SAC 的表现。它们也不是本折验证选中的策略，不能事后替换 `risk_ppo`。

跨四折，risk-only 相对 base PPO 的平衡分数差依次 **−24.19、+4.34、−9.20、+1.12 个百分点**。单独扩展状态的差依次 **−3.61、−2.98、−1.96、+0.30 个百分点**。联合 PPO 比 risk-only 在三折更好，但比 base PPO 仍仅在最近一折分数更高。这些结果支持保留风险预算这一工程能力，不支持宣称更复杂的模型已稳定更优。

全部消融及成对区间见 [ablation_metrics.csv](../reports/runs/research_v4/ablation_metrics.csv)。风险层会改变仓位和股票子组合约束，同时自身使用协方差信息；消融衡量的是这一结构整体，不能唯一归因为某个特征。

## 信息是否有效

固定 alpha=10 的 Ridge 读出只在训练期拟合，用完全落在各分区内的未来五日标签比较基础/扩展特征。不根据结果删特征、调参或重选策略。

| 测试期 | 新特征的收益预测 MSE 变化 | 新特征的波动预测 MSE 变化 |
|---|---:|---:|
| 2019–2020 | +22.19% | +1.64% |
| 2021–2022 | −0.47% | +0.09% |
| 2023–2024 | +0.61% | −3.25% |
| 2025–2026-10-22 | +7.22% | −2.63% |

变化为 `(扩展MSE/基础MSE−1)`，负值才是误差下降。收益预测在三折变差；扩展读出相对训练期均值预测的收益 skill 四折均为负。波动预测只在后两折相对原特征小幅改善；相对于过去20日波动持久性基准，扩展读出在三折更好，但原特征读出也已在这三折更好，不能将全部增益归于新增特征。

因此本轮**没有证明稳定的新增收益信息**。固定线性读出的失败不否定所有可能的非线性信号，也不等同于解释 RL 内部因果机制。全部训练/验证/测试诊断见 [signal_metrics.csv](../reports/runs/research_v4/signal_metrics.csv) 和 [逐样本预测](../reports/runs/research_v4/signal_predictions.csv)。独立重算核对了 1,134 行预测对应的标签、持久性预测与32行指标，最大数值误差约 1.01×10⁻¹⁶，未独立重新拟合 Ridge 系数。

## 成本与统计结论

同一冻结选择在 5→20 bps 单边成本下的累计收益依次变为：**35.22%→34.25%、−18.44%→−18.85%、−2.43%→−3.35%、10.56%→9.75%**。风险调仓存在成本，不是免费保护。最近一折 20 bps 下，选择策略为 9.75% 收益/9.36% 回撤；无 RL 风险规则为 11.92%/9.79%。

主报告 144 项“策略对四个基准”的年化日均超额区间中，没有一个95%区间的下界大于零；这些对比包含选择结果对候选路径的重复引用，并非144个独立实验。验证选中策略的16个区间均包含零。该探索性移动分块bootstrap先按日期平均种子，再以10日块抽样2000次。区间是 **252×日均算术超额** 的条件区间，不是 CAGR、未来胜率或独立样本外盈利证明；未做多重比较校正。

当前适合保留：可解释风险预算、因果市场/账户状态、同约束规则比较、失败关闭的验证冻结与审计。**不把增强信息组设成已经获证的默认 alpha，也不把最近一折的好表现称为全历史成功。**

下一轮研究的优先假设应是：更有区分度且能核验历史可用时间的外部信息、相关性更低且公司行动可审计的资产池，以及跨市场状态更稳健的验证选择。仅继续增加价格衍生指标或在已看过的测试期反复搜索参数，无法解决这里已经暴露的问题。

所有区间都已用于开发；本次是回溯探索研究。账户为分数份额和假定下一开盘成交，没有新增券商实盘验证。收益与回撤平衡的总体目标仍未达到。
