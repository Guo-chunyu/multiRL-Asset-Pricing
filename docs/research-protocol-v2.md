# 研究协议 v2：五算法比较、冻结策略选择与探索性不确定性分析

制定日期：2026-10-20。适用范围：本项目 A 股 ETF 历史行情研究；深度强化学习，不包含 LLM。该文件固定本轮研究的比较方式和解释边界，不能追溯性地恢复测试集的未查看状态。

## 1. 研究状态与可作出的结论

**当前包含 2026 年行情的测试区间已经被查看。新增 SAC、PPO、A2C、加长训练预算、修改选择器或改变候选池后的结果，统一标记为 `retrospective / exploratory`（回顾性、探索性）。不得称为 pristine out-of-sample、从未查看的最终测试，或据此宣称稳定可交易优势。**

按时间划分仍然能阻止训练直接读取未来收益，但不能消除研究者已经根据这段历史调整方法产生的选择偏差。区块 bootstrap 也不能修复这种选择偏差。未来确认性验证需要另行冻结代码、参数、资产池和主要比较，再积累此前未查看的新市场数据。

本轮研究回答三个具体问题：

1. 在相同观测、约束、费用和行情分段下，五种 RL 算法的回顾性表现、优化稳定性及换手有何差别？
2. 用验证集选择一个 RL 策略，与等权基准相比是否存在值得继续研究的净收益差异？
3. 冻结基础策略后，DQN 动态选择是否比验证集选出的单策略、简单平均组合更有用？

不把“框架能运行”“某个种子获胜”“某段置信区间不跨零”单独作为资产定价理论改进或真实交易优势的证据。

## 2. 固定训练与比较计划

| 项目 | 本轮约定 |
|---|---|
| 算法 | TD3、DDPG、SAC、PPO、A2C |
| 训练随机种子 | 7、17、29；保留全部种子，不选择最优种子 |
| 主实验预算 | 每个基础模型 10,000 个环境交互步；DQN 选择器同样 10,000 步 |
| 旧实验预算 | 5,000 步，作为历史版本结果保留；不与新增算法混成同预算比较 |
| 主比较风险罚系数 | 五算法统一为 2；TD3 的 0、8 风险偏好另列消融 |
| 单资产目标权重上限 | 0.5；现金不受该上限限制；持仓被动漂移可超过上限 |
| 基准交易费 | 风险资产买入、卖出每侧 5 bps；现金无交易费 |
| 主要基准 | 同资产池、同执行时序的每日等权调仓 |
| 次要基准 | 买入持有、全现金、动量、反转、学习策略等权混合 |
| 核心统计参数 | 10 个交易日的移动区块；2,000 次重复；双侧 95% percentile 区间；统计随机种子 7 |

10,000 个环境步不代表各算法有相同梯度更新次数、样本复用次数或计算时间。报告每个算法实际 `num_timesteps`、主要超参数、墙钟时间以及 on-policy rollout 整批完成引起的预算超出；不得把环境步相等表述为计算成本相等。是否使用共享时间编码器也必须在每个模型配置中明确。

若将 TD3 的多个风险参数同时加入最终候选池，必须报告 TD3 获得了更多候选配置；不能把较大搜索预算的结果归因于算法本身。五算法主表使用统一风险系数，额外风险模型用于消融及多策略研究。

## 3. 时序划分、训练冻结与选择规则

主实验沿用不重叠的基础训练、meta 训练、验证、测试四段。模型只读取截至决策日的 OHLC 与持仓状态；t 日收盘生成目标权重，在 t+1 日开盘交易。旧仓获得隔夜收益，新仓获得开盘后的收益。每段从现金开始，舍弃跨越段边界的收益；窗口中的历史价格可以来自前一段。

基础模型只在基础训练段优化。进入 meta 训练后冻结基础网络，DQN 在之后的 meta 段学习离散策略编号。验证和测试期间，全部模型只进行确定性推理；允许更新已兑现的账户和影子账户统计，不允许梯度更新、基于测试收益挑选 checkpoint 或重新调整超参数。

固定验证评分为：

```text
validation_score = validation_total_net_return - 0.5 * validation_max_drawdown
```

最大回撤为正的损失比例，评分越高越好。并列时按预先固定的候选注册顺序处理，并记录该顺序。

必须分别报告两个选择结果：

- **single_best_rl：** 只在预先列出的已学习 RL 候选中按验证评分选一个；报告该策略的测试结果。
- **best_overall：** 允许现金、规则策略、混合策略、DQN 与 RL 候选参与；用于展示研究系统的整体选择行为。若现金胜出，表述为“验证选择现金”，不写成“RL 击败市场”。

主要探索性比较预设为 `single_best_rl − equal_weight`。五算法逐项比较、DQN 与等权/DQN 与 single_best_rl、混合组合比较均为次要分析，完整报告而不只展示获胜项。不得读取测试收益后再定义 single-best。

## 4. Expanding walk-forward

计算资源允许时运行 3 折、每折每算法 5,000 步、每折种子 7/17/29。若只完成部分折或种子，按实际完成范围报告，不把它写成完整 3×3 研究。

划分规则与 `expanding_splits` 一致：最后约 30% 日期划为三个互不重叠测试块；每折测试之前保留总日期数的 15% 作为 meta 段、10% 作为验证段；基础训练从固定 lookback 起点逐折向后扩展。所有索引区间为闭区间，每段至少有两个估值日期。每折训练新模型。

后折可以使用已经成为历史的前折测试行情；不能在该行情尚未发生的前折使用它。同一训练种子跨折的测试收益日期不重叠，但不同折仍处于同一市场历史中，不能视为独立市场重复实验。

每折分别输出指标和 bootstrap 区间。**不能将不同折的收益直接拼接后抽取 10 日区块**，因为区块可能跨越现金重置和省略的桥接日期。本轮不把各折重置的组合冒充一条连续实盘净值，也不从三折的均值和标准差计算“独立市场样本”的显著性。

## 5. 同日配对与多个种子的正确汇总

CSV 读取时先去掉初始估值行，它的 `net_return=0` 不代表发生过一次交易收益。对策略与等权基准，以及全部训练种子，要求：

1. 日期唯一、递增，处于同一测试段。
2. 所有日期序列逐项完全一致；发现缺失或额外日期应报错并检查数据。不得静默 inner join、填零、向后填充或压缩成另一份样本。
3. 日收益为扣除已建模执行费用后的 simple return。不能把净值水平、对数收益或已年化数据传入简单收益统计函数。

设 `r[s,t]` 为种子 s 在同一市场日 t 的收益。先计算：

```text
r_bar[t] = mean_s r[s,t]
d[t]     = r_bar[t] - equal_weight_return[t]
```

市场时间序列仍只有 T 个日期，不能把 S×T 个数展平后当作 S×T 个独立市场观察值。`aggregate_seed_returns` 单独报告各种子的累计收益及种子间样本标准差（ddof=1；单种子时为 null），用来描述训练随机性。

按日平均后的路径只是算法跨种子的汇总，不自动等于一个已建模全部费用的可交易组合。它的复利收益与“各个种子累计收益的平均值”一般不同，两个量分别命名，不能互换。bootstrap 区间以给定已训练模型为条件，不包含重新采样行情后再训练模型的全部不确定性。

## 6. 配对移动区块 bootstrap 的估计量

主要估计量为**年化算术平均日超额收益**：

```text
annualized_mean_excess = 252 * mean_t(d[t])
```

它不是 CAGR、Sharpe、胜率或未来一年预期财富增长保证。

实现 `paired_block_bootstrap` 从原始 T 日序列中构造所有长度 10 的重叠连续区块，起点为 0 至 T−10；有放回抽取 `ceil(T/10)` 个区块，拼接后截断为 T 日，重复 2,000 次。它不从序列尾部环绕到开头。策略与基准使用相同日期索引，相当于直接对配对差 `d[t]` 抽样，保留同日关联和区块内部时间关联。

报告重抽样估计量的 2.5% 与 97.5% 分位数作为探索性 percentile 区间。有效样本不足两个完整区块时拒绝计算。固定区块长 10 是本轮约定，不代表已经证明它对所有市场阶段最优；它也不能保留超过区块长度的全部依赖。方法依赖时间序列的适当平稳性/弱依赖近似，非平稳市场下覆盖率未得到保证。

另外报告描述性的累计收益差：

```text
total_return_difference = product_t(1 + strategy_return[t])
                          - product_t(1 + benchmark_return[t])
```

该点估计不附带本函数未计算的置信区间，也不应被解释成 `product(1 + daily_excess)-1`。

这里没有对五算法、多个消融或多个折进行 family-wise 或 FDR 校正。95% 区间是逐比较区间；不将“不含零”直接表述为经多重比较校正的显著优势，也不把 bootstrap 样本中正值比例叫作策略未来盈利概率。所有本轮区间仍受已查看测试期的研究选择偏差影响。

## 7. 消融与压力测试

在查看新一轮结果之前登记以下比较；未运行的项目明确标记为计划，不能作为已完成证据：

| 分析 | 固定项 | 比较项 | 对应问题 |
|---|---|---|---|
| 五算法 | 相同数据、risk=2、10,000 步、三个种子 | TD3/DDPG/SAC/PPO/A2C | 算法选择是否影响优化与回顾性表现 |
| 训练预算 | 同算法、配置、种子与划分 | 5,000 vs 10,000 步 | 增加交互预算是否改善结果，而非只增加回测筛选机会 |
| 风险偏好 | TD3 其余设置 | 系数 0、2、8 | 风险罚项是否改善回撤或仅降低参与度 |
| 策略聚合 | 同冻结候选池 | single_best_rl、等权混合、DQN | 动态选择是否增添价值 |
| 编码器 | 同算法与种子 | 共享时间编码器 vs 已支持的扁平基线 | 表征是否有可观察贡献 |
| 策略多样性 | 同测试/验证日期 | 动作 L1 距离、净收益相关性 | 多个模型是否实际产生不同决策 |
| 专家行为克隆 | 须先有独立实现和测试 | 无模仿 vs 训练期因果专家模仿 | MetaTrader 第一阶段的增量作用；目前属于后续研究 |

费用压力采用 5、10、20 bps，每侧费率，完整重算自融资交易和费用后的持仓。使用同一批冻结模型和已经锁定的验证选择，不在各个费用场景的测试结果上重新选赢家。DQN 可以因新费用下已经兑现的影子收益不同而改变动作，这是冻结模型面对变化状态的推理，不是重新训练。

额外执行延迟、停牌/涨跌停、整数手、最低佣金和冲击成本在没有实现与验证前只能列为限制。当前下一开盘成交、连续份额、足额成交与比例费用的执行模拟不等于实盘。数据复权快照、固定存续 ETF 池及其选择时点也必须在最终报告中保留。

## 8. 与 MetaTrader 的关系

MetaTrader 原文是两阶段方法：先结合 RL 与不同专家的行为克隆形成基础策略，再冻结基础策略，由 meta-policy 每期选择一个策略。在线摘要和用户提供的论文正文一致。原文 §3.2（本地 PDF 第 5 页、印刷页 1577）明确采用策略编号的离散选择，并使用 DQN；加权平均只是其对照方案之一。[论文与版本记录](https://arxiv.org/abs/2210.01774)

本项目吸收冻结策略池和离散选择结构。不同风险惩罚、不同 RL 算法与启发式候选的多样性，与原文专家行为克隆第一阶段不同；当前不能声称完整复现 MetaTrader。Q 值也不是经过校准的盈利概率。当前选择器的净收益必须与单策略及平均策略一起检验。

## 9. 输出与追溯要求

每次运行保留原始数据 SHA-256、资产顺序、日期区间、费用、种子、实际交互步、代码/依赖版本、模型参数、验证选择及全部逐日账本。统计文件还保留 bootstrap 方法、区块长度、重复次数、统计种子、置信水平和市场日期数。

报告应同时展示单种子结果、种子间离散度、同日平均后的配对差区间及完整失败结果。结论用“本次回顾性样本中观察到……”描述；不以新算法在已查看测试期获胜来回溯修改本轮方案。

统计实现依据：移动区块思想来自 Künsch, H. R. (1989), *The Jackknife and the Bootstrap for General Stationary Observations*, Annals of Statistics 17(3), 1217–1241，[DOI](https://doi.org/10.1214/aos/1176347265)。固定长度、无首尾环绕的实现语义亦与 [arch 官方 MovingBlockBootstrap 文档](https://arch.readthedocs.io/en/latest/bootstrap/generated/arch.bootstrap.MovingBlockBootstrap.html)一致。本项目自行实现 NumPy 版本，没有新增 arch 依赖。
