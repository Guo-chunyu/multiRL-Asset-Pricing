# 独立实现审查

日期：2026-10-19。范围：`experiment.py`、`meta.py`、`env.py`、`data.py`、`metrics.py` 及模型加载接口。先开展小样本隔离审查，再进行真实行情长区间运行；后者发现的浮点边界问题及修复见下文。这不是对投资收益的认证。

已确认的事实：

- 基础策略仅在 base-train 段学习，DQN 仅在后续 meta-train 段学习；验证段按既定收益/回撤分数选策略，测试段只调用确定性推理。过去窗口可跨到前一分段，但没有读取决策日之后的行情。
- 每次动作先让旧持仓承担隔夜变化，再于下一开盘调仓。风险资产买卖两侧按真实名义金额扣费，现金不收费。手算测试覆盖跳空、双边费、持仓漂移、被动持有与终止边界。
- 选择器的性能输入只含已兑现收益。影子账户使用自己的持仓计算策略回报，真实执行则把实际账户持仓传给被选策略；持仓敏感策略的专项测试覆盖二者不同的情形。
- 独立实跑两次同配置实验：140 个合成交易日、2 资产、seed 13、每模型 24 步，第二份数据只将测试段 OHLC 乘以 3。两次的 3 个 TD3、DDPG、DQN 共 5 个模型的全部 `state_dict` 张量精确相同，验证选择文件也精确相同。
- 同一审查实验中，保存并重新加载全部模型后，11 个策略的测试指标字典与首次评估精确相同。加载前检查行情文件 SHA-256，行情快照发生变化会拒绝重评。
- 环境、选择器和数据测试联合运行结果为 43 passed。该证据在增加 walk-forward 模块之前取得；完整项目最新测试结果以主流程复验为准。

审查边界：以上实验预算用于验证隔离与复现，不足以评估模型学习效果。策略池当前是不同风险偏好的 TD3 加因果启发式策略，没有实现 MetaTrader 的专家行为克隆阶段。不同种子共用一段行情；稳健性需要多个滚动样本外区间进一步检验。连续份额、理想开盘成交与比例费用仍是研究假设。

## 真实行情运行发现与修复

4只ETF的真实行情中，动量/反转策略的2272个目标权重里，10次因浮点求和令现金残差约为 -2.22e-16，触发严格非负校验。已以两个真实输入建立先失败再通过的回归测试：风险权重只向下校正总和，并把现金残差限制为非负；没有放宽真实负仓位校验。随后动量、反转及含独立影子账本的选择器各完整回放1136步，无同类错误。softmax动作转换的10032个边界/随机动作没有该问题。

长训练已完成的基础模型检查点被保留。新增显式恢复模式：必须匹配原数据哈希、配置、时间分段、资产顺序和运行库版本，才能重用完成的检查点；检查点步数和种子也需一致。未完成的模型从头训练，不声称恢复其优化器中途状态。恢复流程不会改写已有模型文件，并有端到端回归测试验证。
