# v4：信息与风险配置如何实现

本轮在 `CorporateActionPortfolioEnv → RobustPortfolioEnv` 之上增加 `InformationRiskEnv`。基础会计未改：t 日收盘产生目标，t+1 日开盘换仓，随后按收盘价格计价；应收分红直到实际支付才可买入。日频记账和五日调仓分开。

## 观察与动作

`src/rlasset/risk_env.py` 的 `market_features` 提供不依赖账户的市场特征：原来的 24 个价格状态，加上 13 个成交量/相对动量/下行风险/相关性等状态。再接入现金优先的当前持仓、调仓阶段、账户回撤和可用现金/应收占比，完整观察为 45 维。

只有成交量是原 v3 未利用的独立行情字段；其余市场扩展主要是价格的结构化变换。特征多不自动等于有效信息，必须由消融和训练期以外的读出诊断检验。

`action_to_weights` 的前一个动作控制风险预算，其余动作控制股票之间的相对比例：

```python
budget = 0.10 * np.exp(np.log(2) * action[0])  # 5%—20%年化预算
scores = np.exp(0.75 * action[1:])
target = env.risk_target(scores, budget)
```

`risk_target` 先把 scores 分配成和为 1 的股票子组合 q（单资产至多 50%），再计算历史风险并确定股票总仓位：

```python
sigma = max(sigma_20_days, sigma_60_days, 0.01)
exposure = min(1.0, budget / sigma)
target = np.r_[1 - exposure, exposure * q]
```

例如同样选择 10% 风险预算，估计股票子组合年化波动为 25% 时，目标股票仓位约 40%，其余为现金；估计波动 8% 时最多持有 100% 股票，无杠杆。实际风险仍可能超过目标，周调、开盘跳空和估计误差都可能造成偏离。

两段窗口协方差均取截至决策收盘的对数收益，采用固定 25% 对角收缩。不是用未来实现波动决定当前仓位。缓存逐行计算因果特征；未来行情或公司行动变化不应影响过去。

## RL 学什么

模型仍通过真实 FinRL 的 `DRLAgent.get_model` 创建，底层 PPO/SAC/TD3 学习动作。风险映射位于环境中，SB3 学的是原始动作在这个映射下的价值；本项目没有把这一层作为可微优化器反向传播。

收益信号继续是扣费后的 log 增长，减去过去 120 日简单收益协方差的风险惩罚。这是训练奖励；惩罚不会再从账户现金扣一次。模型可以学习在市场和账户状态变化时选择不同的预算、股票比例，是否学成取决于实验证据。

## 为什么有六组模型

| 候选 | 扩展信息 | 风险配置 | 算法 |
|---|---|---|---|
| base_ppo | 关闭 | 关闭 | PPO |
| signal_ppo | 开启 | 关闭 | PPO |
| risk_ppo | 关闭 | 开启 | PPO |
| joint_ppo | 开启 | 开启 | PPO |
| joint_sac | 开启 | 开启 | SAC |
| joint_td3 | 开启 | 开启 | TD3 |

前四组用于拆开两个模块的影响，后三个 joint 模型用于算法敏感性。risk-only 本身也用到相关性等风险信息，因此它衡量风险估计与配置结构的整体增量。增强信息组包含账户状态，不能把组间差异全归于成交量。

10% 目标波动等权/逆波动规则使用同一个风险层，完全不需要 RL。若这些规则表现相当或更好，就不能将风险层本身的价值称为深度学习优势。50% 固定等权还用于检验“降低仓位”本身的作用。

## 策略选择和论文关系

`study_v4.py` 将训练、验证选择、测试分开。每折按照三个种子的验证期平均“累计收益−0.5×最大回撤”选择一个固定 RL 候选；另保存允许两个规则候选胜出的选择。所有选择、模型与账本哈希冻结后才能测试。三个 joint 模型的目标均值也作为固定混合对照，但不参与选择。

这保留了多策略训练、冻结和比较的思路。v4 没有训练按日切换的 DQN，也没有实现 MetaTrader 的专家行为克隆目标；旧 DQN 不属于本轮新会计结果。DDPO 提供持仓、信号、风险、费用共同决定控制的理论视角，但新的多资产风险映射不继承其单资产线性二次情形的解析最优保证。

## 信息价值诊断与审计

`signal_diagnostics.py` 用固定 Ridge 线性读出，对比基础/扩展特征对未来五日收益和波动的预测。标签不能跨分区，归一化和系数仅在训练期拟合；结果不反过来修改特征或测试选择。读出失败不能否定所有非线性关系，读出改善也不代表 RL 已利用它。

`scripts/audit_research_v4.py` 从 raw 价格和公司行动重新构建现金/份额/费用/NAV，并独立计算风险估计。审计器不复用生产环境的风险函数，且核验规则的 10% 预算、五日调仓和冻结选择。

完整固定条件与局限见 [研究协议](research-protocol-v4.md)。所有历史区间已用于开发，本轮仍是探索性研究；下一段足够长的新数据才可能提供更强的独立确认。
