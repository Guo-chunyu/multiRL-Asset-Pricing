# A股ETF强化学习组合优化：研究与实现设计

2026-10-19。用户确认研究对象为A股股票/ETF，所谓“大模型”指深度强化学习，不包含LLM。

## 路线选择与边界

按用户指定的顺序研究DDPO、MetaTrader、FinRL及RLPortfolio。DDPO原文的DDPG在可解析单资产问题上提供方法检验，不构成A股多资产市场可盈利或神经网络收敛的保证。TD3以双critic、延迟actor更新与target平滑改进DDPG，作为首版主线；DDPG保留同预算对照。PPO/SAC也是可行候选，但首版先集中检验确定性连续控制路线，降低实验自由度。

MetaTrader提供冻结基础策略后训练DQN选择器的两阶段结构。首版采用不同风险惩罚的TD3策略及动量/反转规则构建候选池，DQN观察市场与候选策略过去净收益进行离散选择；这是受论文启发的改造，不是原论文行为克隆目标的完整复现。必须比较单策略、固定等权混合、DQN选择器，并报告候选策略是否确实产生不同权重。

## 数据与交易时点

首版固定ETF研究池：510300、510500、159915、510050。非投资推荐，固定存续ETF回溯仍有选择偏差。数据接口支持显式选择AKShare/Eastmoney或Tencent日频后复权OHLC，保留CSV哈希、下载时刻、数据版本；不自动回填、不把模拟数据当市场数据。因东方财富连接不稳定，本次实跑使用Tencent；因早期159915停牌缺口，使用2022年起的完整区间。当前快照不是历史时点复权数据库，供应商hfq不等同于已核实的分红再投资总回报。

在交易日t收盘后，以截至t的窗口和收盘后权重形成目标。t+1开盘前，旧仓承担open[t+1]/close[t]的隔夜收益；在开盘成交并扣费，新仓承担close[t+1]/open[t+1]的日内收益。一天只交易一次，不将t+1的数据加入t的观测。初始全现金，现金收益暂设0；long-only、无杠杆，单只ETF目标权重上限0.5，漂移后允许被动超限。

手续费对风险资产买卖金额收费，现金不重复收费。自融资比例mu解方程mu = 1 - c sum_i |mu*w_i - pre_i|，费用含单边佣金和线性滑点的研究假设。ETF默认不加股票印花税。连续权重模型暂不模拟100份整数手、最低佣金、涨跌停排队、停牌、冲击和集合竞价成交；因此它是研究回测，不能直接接实盘。股票执行规则需要独立扩展。

## 模型、训练与验证

状态为局部归一化的close/high/low价格张量及当前权重。共享时间卷积借鉴RLPortfolio的EIIE参数共享思想；不宣称复现其即时policy-gradient/PVM训练器。奖励为净对数收益减历史协方差风险罚项，风险矩阵仅使用截至决策时刻的样本。净值评价始终使用未混入风险罚项的真实模拟收益。

按日期分成基础策略训练50%、选择器训练20%、验证15%、测试15%，warmup单独留出；各阶段状态日期不重叠，跨边界单期收益舍弃，观测可以使用早期历史。基础模型只见第一段训练；选择器训练阶段所有候选冻结，影子组合独立推进并在收益已实现后更新表现状态。验证集选择最终部署候选，测试只评价，所有对照表保留以便研究。不得依据测试结果重新选择种子/参数。

输出每种子的模型、净值/权重/选择记录、指标、验证选择结果、配置、版本、数据哈希。比较等权每日调仓、买入持有、现金、动量、反转、DDPG、不同TD3风险偏好、等权混合和DQN。多种子结果用于描述训练不确定性，不能代替独立市场样本的统计显著性。

## 分工与验收

模块：data/download（数据与校验）、env（资产会计）、finrl_adapter（真实DRLAgent接口）、extractors（共享时间卷积）、meta（冻结候选与DQN环境）、experiment/cli（训练回测）、theory（DDPO解析基准）、metrics（评价）。FinRL固定到读取的提交，通过窄加载绕开根模块的多交易平台依赖；无静默SB3降级。RLPortfolio保留源码与许可证并记录借鉴位置。

验收：手算会计/费用/漂移、未来数据扰动不改变当前观测、分段隔离、解析Bellman一致性、指标极端值；真实FinRL训练与保存重载；离线模拟和真实ETF完整端到端实验。成功运行与获得投资优势是两个独立结论，报告不能混淆。
