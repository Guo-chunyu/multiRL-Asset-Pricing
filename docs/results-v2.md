# 五算法研究、策略选择与成交模拟

研究日期：2026-10-20。代码、训练、滚动比较、费用压力、风险消融和模拟交易均已实际执行。**当前验证规则选出的统一 RL 候选是 PPO；证据尚不支持稳定超额收益或实盘上线。**

这一轮复用了已经查看过的历史测试区间，属于回顾性、探索性研究。训练仍严格按时间隔离，但隔离不能消除研究者已经接触测试结果的偏差。完整方法见[研究协议](research-protocol-v2.md)，算法与论文关系见[五算法理论说明](research/algorithm-comparison.md)。

| 风险消融 | TD3 风险系数 0/2/8，同一真实随机种子 7/17/29、同一 10,000 步预算 |

## 选择结果与主测试期

主测试收益日期为 2026-01-29 至 2026-10-16，共 170 期；2026-01-28 是初始估值/首次决策日。以下为扣除每侧 5 bps 费用后的三个种子平均累计收益，不是年化收益：

| 策略 | 平均累计收益 | 种子间标准差 |
|---|---:|---:|
| TD3（风险系数 2） | −14.02% | 4.08 个百分点 |
| DDPG | −7.07% | 8.24 个百分点 |
| SAC | −5.37% | 5.21 个百分点 |
| PPO | −6.76% | 4.08 个百分点 |
| A2C | −4.31% | 7.46 个百分点 |
| 五种 RL 权重简单平均 | −6.85% | 0.58 个百分点 |
| DQN 动态选择 | −3.92% | 5.62 个百分点 |
| 每个种子验证期最佳 RL | −13.43% | 见自动报告 |
| 等权每日调仓 | −12.35% | 0 |
| 买入持有 | −12.63% | 0 |
| 现金 | 0.00% | 0 |

**统一候选 PPO 的选择依据是验证期。** 各算法三个种子的平均验证分数（累计净收益 − 0.5×最大回撤）依次为：PPO 0.13040、DDPG 0.12702、SAC 0.11083、A2C 0.08825、TD3 0.00641。没有根据测试收益挑 A2C 或 DQN，也没有挑选最好的随机种子。

单独对每个种子选择时，最佳 RL 分别为 A2C、DDPG、SAC，其测试收益为 −12.92%、−16.37%、−11.01%。允许规则策略参加的整体选择，三个种子均选中动量，其测试收益 −12.34%。这说明验证期赢家并不能稳定延续到后续行情。

PPO 相对等权的年化算术平均日超额收益 95% 区间为 **[−20.71%, +29.57%]**；DQN 为 **[−13.69%, +36.74%]**；逐种子最佳 RL 为 **[−9.00%, +4.56%]**。这些不是 CAGR 区间或未来胜率；均包含零，不能声称统计上稳定优于等权。各项比较未进行多重检验校正，且这仍是探索性结果。

## 滚动窗口

每折分别训练、从现金起步，省略跨折桥接收益。表内均为每折三个种子的平均累计收益，不拼接为连续实盘净值。

| 测试收益日期 | 验证期最佳单一 RL | DQN 动态选择 | 等权 |
|---|---:|---:|---:|
| 2025-05-14 至 2025-10-30 | +0.13% | +4.81% | +29.07% |
| 2025-11-03 至 2026-04-23 | +7.45% | +2.02% | +8.06% |
| 2026-04-27 至 2026-10-16 | −8.08% | −11.57% | −13.51% |

第一折上涨阶段明显落后：最佳单一 RL 和 DQN 相对等权的年化算术超额区间全为负。后两折对应区间包含零。低股票暴露可能在下跌期减少损失，同时错过上涨行情；目前证据不能把这种暴露差异解释成稳定择时能力。

各折按平均验证得分选出的统一算法分别为 A2C、SAC、SAC，也没有保持统一赢家。完整逐折结果保存在 `runs/walkforward_v2`。

## 费用与风险系数

| 策略 | 每侧 5 bps | 每侧 10 bps | 每侧 20 bps |
|---|---:|---:|---:|
| TD3 λ=2 | −14.02% | −19.75% | −29.50% |
| PPO | −6.76% | −6.81% | −6.93% |
| A2C | −4.31% | −4.34% | −4.39% |
| DQN | −3.92% | −7.78% | −10.18% |
| 等权 | −12.35% | −12.44% | −12.61% |

重评时网络冻结，但真实持仓及 DQN 影子统计会随费用变化，因此动态选择路径也可能改变。DQN 和 TD3 对费用的明显敏感性是后续改进的重要目标，不应由较低费用时的好看结果掩盖。

同随机种子、同预算的 TD3 风险消融：λ=0 平均 −7.39%，λ=2 平均 −14.02%，λ=8 平均 −5.12%。结果非单调，说明训练和目标函数的相互作用较强，不能仅因这段测试上 λ=8 较好就把它重新指定为“最优参数”。原主比较 λ=2 保持不变。消融文件在 `runs/risk0_v2`、`runs/risk8_v2`，额外的小候选池 DQN 结果不混入五算法主表。

## 模拟执行证据

使用独立抓取的 **未复权** OHLCV；与信号数据逐日、逐代码对齐。100 万元初始资金，100 份整数买入、T+1 可卖账本、先卖后买、现金不透支、每侧 3 bps 佣金/最低 5 元、2 bps 滑点、成交量容量、部分成交和余量取消、停牌/涨跌停方向限制、重复订单幂等。

账户持仓受实际模拟成交影响，再反馈给下一日模型；不是把理想回测目标权重直接当作已经成交。每笔订单和每日 NAV 均保存并对账。统一验证候选 PPO 也单独进行了回放。

| 组合来源 | 正常行情模拟的三种子平均价格收益 |
|---|---:|
| 统一验证候选 PPO | −8.00% |
| 每种子验证期最佳 RL | −14.90% |
| DQN 动态选择 | −4.47% |
| 验证期整体选择（动量） | −13.84% |
| 等权 | −13.98% |

这些是**未计现金分红的模拟价格收益**，且账户规则不同，不能与前面的复权研究收益作同口径归因比较。人为扰动场景另外按固定日期注入停牌、薄成交量和涨跌停阻挡；它用于检验拒单/部分成交后账户仍可继续运行，不是实际历史停牌记录，也不能因某次扰动减少亏损就声称模型更强。

日线全天成交量作为离线容量代理，开盘加滑点属于撮合假设；没有逐笔排队、真实券商连接、实际订单回报、公司行动现金/份额调整。因此本轮证明的是所实现约束下的执行流程与会计一致性，**没有证明真实实盘成交能力或盈利能力**。

详细规则：[execution.md](execution.md)。正常与压力场景全部记录：[paper_v2/summary.json](../reports/runs/paper_v2/summary.json)；例如 [seed 7 PPO 正常订单](../reports/runs/paper_v2/seed_7/normal/consensus_on_validation/orders.csv) 和 [逐日账本](../reports/runs/paper_v2/seed_7/normal/consensus_on_validation/ledger.json)。

## 复核与交付

自动测试覆盖费用守恒、权重漂移、时间切分、模型保存重载、五算法预算、旧模型兼容、DQN 影子时序、未来信息扰动、统计区块采样、原始价格口径与模拟订单。未来价格扰动审计检查全部五个模型和 DQN 的参数/优化器状态、验证指标和选择结果精确不变；人为注入未来归一化泄漏时测试能检出。

本轮最终 **198 项测试全部通过**；独立逐笔重建并核对 **30 份账本、14,057 条订单回执** 的现金、份额、NAV 与 T+1 约束，84 个模型文件已记录 SHA-256。测试原始记录：[pytest_v2.xml](../reports/runs/pytest_v2.xml)；独立审计：[review-v2.md](review-v2.md)；最终文件哈希和逐笔对账记录：[verification_v2.json](../reports/runs/verification_v2.json)。复现命令及环境说明见 [README](../README.md)。

研究下一阶段应在冻结当前模型与比较规则后积累未查看的新数据，并补齐公司行动、实时行情与券商沙盒。当前优先研究问题是降低切换换手、控制随机种子敏感性，以及验证收益改善是否只来自降低市场暴露；不是依据现有测试收益再选一个赢家。
